# Дневник старшеклассника

Мобильное веб-приложение для целей, заметок, знакомства с профессиями и планирования индивидуального образовательного маршрута.

HTML, CSS и JavaScript без сборки и серверной базы данных. Цели, черновики, заметки и профиль сохраняются в браузере посетителя. Для переноса записей на другое устройство или адрес используйте экспорт и импорт резервной копии в профиле. Форма регистрации создаёт локальный профиль, а не учётную запись на сервере.

## Размещение на GitHub Pages

1. Загрузите файлы приложения в корень репозитория.
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).
3. Дождитесь завершения публикации и откройте адрес, показанный в Settings → Pages.

Приложение поддерживает размещение как в корне домена, так и в подпапке проекта. Мобильная установка и офлайн-режим доступны после успешной первой загрузки по HTTPS. Личные данные пользователей не включены в исходный код.
